# Security policy

Taskboard AI Lab is a fictional, local-only teaching repository. It has no
production accounts, hosted service, authentication, payment flow, or secret
store. Do not use it with real credentials or personal data.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or a private security
advisory for this repository when that option is available. If it is not
available, contact the owner through the [GitHub profile](https://github.com/amikad09)
before sharing sensitive details. Do not put tokens, private exploit steps, or
personal data in a public issue.

Include the commit or release, affected file, smallest safe reproduction, and
the impact you observed. Please allow time for acknowledgement and a fix
before public disclosure.

If a secret is exposed, revoke it with its provider first. Removing a line
from the latest commit does not remove it from Git history; stop sharing the
copy and preserve only a redacted incident note.
