# Make the method yours

Add a filter for all, complete, or open tasks. Derive the visible rows from the
current response and the selected filter; keep the underlying task records
unchanged. This is different from the guided open-count exercise.

Map, plan, implement, verify and review again. Predict the relevant files before inspecting them. Compare your exclusions and retries with the guided task; do not claim savings without comparable data.

Check empty results, keyboard selection, toggle/undo within a filtered view,
and failure or uncertain response states. Keep the filter as UI state and the
task records as server state. Make a new brief before opening the reference.
