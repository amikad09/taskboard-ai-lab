# Fork-fast or learn-by-doing

The public starter is at
<https://github.com/amikad09/taskboard-ai-lab>. It is intentionally small so a
learner can fork it, install the pinned toolchain, and reach a real feature in
one sitting.

## Fork-fast route

```bash
git clone https://github.com/amikad09/taskboard-ai-lab.git
cd taskboard-ai-lab
pnpm install --frozen-lockfile
pnpm verify
```

Then run the backend and web app from the root README and start the
open-task-count brief in `docs/plans/active.md`.

Fork-fast is a shortcut to a known starting point. It does not make the code
production-ready, remove the need for checks, or grant access to an account,
server, credential, or publication channel.

## Guided route

The guided route explains why the package graph, focused context, short rules,
checks, recovery notes, and fresh review exist. Save a context decision, task
brief, workflow trace, proof receipt, review, repair note, usage note, and
handoff as you go.

## Public boundary

This repository contains fictional local-only data. Do not commit secrets,
private source, generated reports, personal logs, or production data. Rules
guide an agent but do not grant permission. Human approval and tool boundaries
still control external, destructive, and credentialed actions.
