# Approval boundary

Rules and prompts describe intent. They do not grant permission. Pause and ask
the owner before any action that can add dependency or spend, contact an
external service, use a credential, delete or overwrite data, publish, deploy,
or change repository visibility.

| Request | Why it has side effects | Safe read-only alternative | Decision |
| ------- | ----------------------- | -------------------------- | -------- |
|         |                         |                            | pending  |

A fork of this repository is local teaching material. It contains no production
credentials, account access, or permission to publish on the owner's behalf.
