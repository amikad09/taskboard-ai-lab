# Honest context comparison

This exercise compares two packets for the same open-task-count task.

- **Focused packet:** active plan, project map, relevant browser/client files,
  response contract, and named checks.
- **Broad packet:** the same task plus unrelated docs, all source files, and
  historical material.

Keep the task, candidate, model/provider, settings, acceptance cases, review,
and repair policy comparable. Record retries, tool calls, elapsed time,
review findings, and native usage fields when available. If a field is missing,
write `unknown`.

Do not report a saving when the broad run fails, uses different proof, or gets a
better model. A shorter prompt is not automatically cheaper; total work per
accepted result is the teaching measure.

The instructor packet may contain labelled captures. Any example without native
provider telemetry must say `illustrative` and must not be used as a percentage
claim.
